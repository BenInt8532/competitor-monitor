# Competitor Monitor

Веб-приложение для сравнения крипто-обменников **USDT → RUB**: не по слогану, а по признакам безопасной выплаты (счёт, банковский перевод, наличные — не только СБП).

Читает текст, файлы, сайты и отзывы, складывает материалы одного обменника в профиль и показывает сводную таблицу.

Учебный проект курса «Промпт-инжиниринг 3.0» (Зерокодер), урок PEm08.

---

## Возможности

- Очередь до 10 сайтов: скриншот и текст лендинга, отзывы, курс и способы выплаты.
- Файлы: скриншоты, PDF, Word, HTML/MHTML, таблицы XLSX/CSV, заметки TXT/MD/JSON. HEIC с айфона конвертируется в JPEG.
- Текст: разбор заметки. Если в тексте есть ссылка, а данных мало — приложение само открывает сайт.
- Отзывы: BestChange (отзывы и финансовые претензии) и сторонние площадки. Сайты «вернём ваши деньги» в сбор не попадают.
- Сравнение: одна строка на обменника, курсы с BestChange, выгрузка CSV.
- Имя читается из домена, логотипа или файла. Вручную вводится только во вкладке «Текст».

---

## Как это работает

Три источника **склеиваются**, а не заменяют друг друга:

1. **Модель (GPT-4o через ProxyAPI)** — флаги безопасности, резюме, оценка доверия.
2. **Лендинг (Selenium + Chrome)** — скриншот и видимый текст страницы.
3. **BestChange** — курс USDT/RUB и каталог способов выплаты.

Профиль копится между запусками (`competitors.json`). Лента разборов — отдельно (`history.json`).

```
файл / текст / URL
        │
        ▼
   разбор моделью
        │
        ├── мало данных и есть ссылка → открыть сайт
        └── есть имя или домен → таблицы BestChange
        │
        ▼
   история + профиль
        │
        ▼
   вкладка «Сравнение»
```

## Установка

```powershell
cd путь\к\competitor-monitor
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Скопируй `env.example` в `.env` в этой же папке и вставь ключ:

```
PROXY_API_KEY=...
OPENAI_MODEL=gpt-4o-mini
OPENAI_VISION_MODEL=gpt-4o-mini
```

Файл `.env` в git не попадает. Если ключ уже лежит в `.env` на уровень выше этой папки — его тоже подхватит.

## Запуск

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

В браузере: [http://127.0.0.1:8000](http://127.0.0.1:8000). Окно PowerShell не закрывай.

Остановка: **Ctrl+C**. После правки кода запусти команду снова.

| Кусок команды | Смысл |
|---|---|
| `.venv\Scripts\python.exe` | Python проекта со всеми библиотеками |
| `-m uvicorn` | веб-сервер |
| `backend.main:app` | файл `backend/main.py`, объект `app` |
| `--host 127.0.0.1` | только этот компьютер |
| `--port 8000` | адрес в браузере |

Проверка: [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health) → `{"status":"ok"}`.

Если порт 8000 занят: `--port 8004` и браузер `http://127.0.0.1:8004`.

`python run.py` поднимает тот же сервер с автоперезагрузкой. Для разбора сайтов используй команду uvicorn выше.

## Интерфейс

### Анализ

- **Ссылки** — до 10 URL списком или по одной. По умолчанию ищутся отзывы. Один сайт — около минуты.
- **Файлы** — пачка разных форматов. Таблица со ссылками разбирается по строкам: каждая строка — свой обменник, URL попадают в очередь.
- **Текст** — поле имени и необязательный курс ₽/USDT (он важнее таблицы BestChange).

Форматы: PNG, JPG, WEBP, GIF, HEIC · PDF, DOCX · HTML, MHTML · XLSX, CSV · TXT, MD, JSON.

PDF без текстового слоя (скан) загрузи как картинку. OCR в приложении нет.

### Папки data/

Разбирает `notes.md` в каждой подпапке `data/`. Заметки со ссылкой дозаполняются с сайта.

### Отзывы

Только отзывы, без лендинга. По домену открываются:

- `https://www.bestchange.ru/<слаг>-exchanger.html?filter=reviews`
- `…?filter=claim` — финансовые претензии

Слаг — первая часть домена: `grumbot.net` → `grumbot`.

### Сравнение

Таблица из накопленных профилей.

- **Обновить курсы** — читает таблицы BestChange для всех известных обменников.
- **Скачать CSV** — разделитель `;`, UTF-8 с BOM (Excel открывает сразу).

Курс в таблице только для чтения. Доверие — оценка по чеклисту безопасности, не рейтинг биржи.

### История

Лента разборов. Удаление обменника стирает его и из профиля, и из ленты.

## Курс ₽/USDT

1. Число, вписанное руками во вкладке «Текст».
2. Таблица BestChange на сумму **1000 USDT**.
3. Число из заметки, если оно в коридоре разумного курса (примерно 30–200 ₽).

С лендинга курс не берётся: на странице рядом висят BTC и обратная пара.

Порядок таблиц для курса — первая, где обменник нашёлся:

1. Расчётный счёт RUB
2. Банковский перевод RUB
3. СБП
4. Наличные RUB

Сбербанк, Т-Банк и карта Visa/MC читаются только как способы выплаты, не как источник курса.

Курс ЦБ — справка для спреда, не курс обменника.

---

## Оценка доверия

Модель ставит балл 0–10 по чеклисту. Тяжёлый красный флаг ставит **потолок**: зелёный «быстрая поддержка» его не отменяет.

| Категория | Потолок | Пример |
|---|---|---|
| `card_block` | 3 | жалобы на блокировку карты или счёта после выплаты |
| `splitting` | 4 | дробление на мелкие платежи |
| `after_payment` | 4 | документы или доплата после отправки крипты |
| `aml_hold` | 4 | заморозка под AML и комиссия за разморозку |
| `bank_access` | 4 | «телефон в руках», кабинет банка открыт на время сделки |

Остальные красные флаги минусуют балл, потолок не ставят.

Если модель балл не ставила, а флаги уже есть — в таблице подпись «по флагам». В профиле среднее по материалам не поднимается выше потолка самого тяжёлого флага.

Дизайн (`design_score`) — первое впечатление от сайта, не безопасность выплаты.

---

## Критерии в промптах

Полный список: `backend/services/openai_service.py`, блок `SAFETY_CRITERIA_BLOCK`.

**Зелёные:** выплата одним платежом; реквизиты счёта / банковский перевод; наличные; AML до отправки крипты; фиксация курса в заявке; большой резерв и живые отзывы.

**Красные:** дробление выплаты; только СБП; блокировка карты; AML/KYC после получения крипты с комиссией за разморозку; смена кошелька; увод в Telegram; «телефон в руках»; запрос сид-фразы.

Маркетинг («24/7», «удобный интерфейс») в флаги не попадает. Обвинение без даты и суммы — в `ignored_claims`.

## Структура проекта

```
competitor-monitor/
  backend/
    main.py                  эндпоинты FastAPI
    config.py                настройки и путь к .env
    utils.py                 ссылки, имена, выплаты, потолки траста
    models/schemas.py        вход и выход API
    services/
      openai_service.py      промпты и GPT-4o
      parser_service.py      Selenium: страница → скрин + текст
      reviews_service.py     отзывы
      rate_lookup_service.py курсы и выплаты BestChange
      enrichment_service.py  дозаполнение с сайта
      ingest_service.py      запись в историю и память
      memory_service.py      профили
      history_service.py     лента разборов
      file_service.py        файлы → текст или картинка
      pdf_service.py         текст из PDF
      table_service.py       XLSX/CSV как список конкурентов
      rates_service.py       курс ЦБ
      summary_service.py     сводная таблица и CSV
  frontend/                  index.html, app.js, styles.css
  env.example
  requirements.txt
  run.py
```

Заметки для вкладки «Папки data/»: `data/competitor-N/notes.md` рядом с проектом (папка урока) или внутри репозитория, если клонировали отдельно.

## API

Схема: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | интерфейс |
| GET | `/health` | проверка, что сервер жив |
| GET | `/config` | лимит очереди и список форматов |
| POST | `/analyze/text` | текст |
| POST | `/analyze/file` | файл |
| POST | `/urls/parse` | текст → список ссылок |
| POST | `/analyze/url` | сайт: лендинг + отзывы + BestChange |
| POST | `/analyze/reviews` | только отзывы |
| POST | `/analyze/batch` | все `notes.md` из `data/` |
| GET | `/rate` | курс USD ЦБ |
| GET | `/summary` | сводная таблица |
| GET | `/summary/export` | таблица CSV |
| POST | `/summary/rates/refresh` | обновить курсы |
| GET | `/competitors` | профили |
| POST | `/competitors/merge` | склеить два профиля |
| POST | `/competitors/rename` | переименовать |
| POST | `/competitors/remove` | удалить обменника |
| DELETE | `/competitors` | очистить память |
| GET / DELETE | `/history` | лента разборов |

Картинки загружаются через `/analyze/file`.
