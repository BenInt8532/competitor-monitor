# Competitor Monitor — анализатор крипто-обменников

Учебное веб-приложение: помогает сравнить обменники **USDT → RUB** не по слогану, а по признакам безопасной выплаты (счёт / перевод / наличные, не только СБП).

Читает текст, файлы, сайты и отзывы, складывает всё в карточку конкурента и показывает сводную таблицу.

Сделано как ДЗ урока **PEm08. Проект: мультимодальное приложение**
(курс «Промпт-инжиниринг 3.0», платформа Зерокодер).

Дневник разработки, грабли и прогоны — в отчёте урока:

`../otchet-PEm08-multimodalnoe-prilozhenie.md`

## Что умеет

| Что загружаешь | Что происходит |
|---|---|
| Ссылки на сайты (до 10) | Selenium открывает лендинг (скриншот + текст), параллельно собирает отзывы, курс и способы выплаты берёт с BestChange |
| Файл | Картинка → vision-модель; PDF/Word/HTML/текст → сначала в текст, потом разбор; таблица XLSX/CSV со ссылками → по строке на обменника |
| Текст / `notes.md` | Разбор заметки. Если есть ссылка, а выплаты или оценки сайта ещё нет — приложение само заходит на лендинг |
| Отзывы отдельно | BestChange (отзывы + финансовые претензии) и сторонние площадки |
| Вкладка «Сравнение» | Одна строка на обменника из всего накопленного; кнопка курсов; выгрузка CSV |

Имя обменника руками вводится **только** во вкладке «Текст». Из ссылки берётся домен (`coindrop.trade` → `CoinDrop`), со скрина — логотип, из файла — заголовок или имя файла.

Сайты вида «вернём ваши деньги» в сбор отзывов не попадают: сначала чёрный список доменов, затем правило в промпте.

## Как устроено простыми словами

Три независимых источника, которые **склеиваются**, а не заменяют друг друга:

1. **Модель (GPT-4o через ProxyAPI)** — читает текст/скрин и ставит флаги безопасности, резюме, оценку доверия.
2. **Лендинг (Selenium + Chrome)** — скриншот страницы и видимый текст. Нужен, когда в заметке мало данных.
3. **BestChange** — таблицы направлений. Отсюда **курс** (не с лендинга: там рядом висят BTC и обратная пара, модель их путает) и **каталог способов выплаты**.

Память живёт между запусками: скрин + Word + отзывы + строка таблицы про одного обменника складываются в один профиль (`competitors.json`). Лента «что только что разобрали» — отдельно (`history.json`).

```
файл / текст / URL
        │
        ▼
   разбор моделью
        │
        ├── если скупо и есть ссылка → открыть сайт
        └── всегда, если есть имя/домен → таблицы BestChange
        │
        ▼
   история + профиль конкурента
        │
        ▼
   вкладка «Сравнение»
```

## Что нужно на компьютере

- Windows 10/11, PowerShell
- Python 3.11+ (в проекте уже есть папка `.venv`)
- **Google Chrome** — без него Selenium не откроет сайты и BestChange
- Ключ [ProxyAPI](https://proxyapi.ru/) (OpenAI-совместимый доступ к GPT-4o)

Сеть: приложение ходит на лендинги обменников, `bestchange.ru`, поиск DuckDuckGo (сторонние отзывы) и `cbr.ru` (курс доллара ЦБ).

## Запуск

Рабочая команда (без автоперезагрузки):

```powershell
cd "D:\Claude Code\Prompt Engineering\PEm08 Проект мультимодальное приложение\competitor-monitor"
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Когда в окне появится `Uvicorn running on http://127.0.0.1:8000` — открой в браузере тот же адрес. Окно PowerShell не закрывай.

Остановка: **Ctrl+C**. После правки кода — снова Ctrl+C и те же две команды. Без `--reload` сервер новый код сам не подхватывает.

Что значат куски команды:

| Кусок | Смысл |
|---|---|
| `.venv\Scripts\python.exe` | Python этого проекта, со всеми библиотеками |
| `-m uvicorn` | веб-сервер |
| `backend.main:app` | папка `backend` → файл `main.py` → объект `app = FastAPI(...)` |
| `--host 127.0.0.1` | только этот компьютер |
| `--port 8000` | адрес заканчивается на `:8000` |

`python run.py` — та же программа, но с `reload=True`. После открытия сайтов через Selenium она часто зависает («Reloading…», порт занят, кнопки отдают 404). Для вкладки «Анализ» по ссылкам используй команду uvicorn **без** reload.

Если порт занят — либо останови старый процесс Ctrl+C, либо укажи `--port 8004` и открой `http://127.0.0.1:8004`.

Проверка, что сервер жив: `http://127.0.0.1:8000/health` должен ответить `{"status":"ok"}`.

## Интерфейс

Пять вкладок.

### Анализ

Три блока на одной странице:

- **Ссылки** — очередь до 10 URL. Можно одной строкой или списком. Галочка «искать отзывы» включена по умолчанию. На одну ссылку уходит около минуты (два окна Chrome: лендинг и отзывы).
- **Файлы** — пачка разных форматов. Если в заметке есть ссылка, а выплаты нет — сам сходит на сайт (~10–60 сек). Таблица со ссылками не кормится модели как «один обменник»: строки → профили, URL → очередь сверху.
- **Текст** — единственное место с полем имени. Курс ₽/USDT можно вписать руками: он важнее таблицы BestChange.

Поддерживаемые файлы: PNG, JPG, WEBP, GIF, HEIC · PDF, DOCX · HTML, MHTML · XLSX, CSV · TXT, MD, JSON.

PDF-скан (картинка страницы без текстового слоя) прочитать нельзя — нет OCR. Такой файл сохрани скриншотом.

HEIC с айфона перед отправкой в модель сам конвертируется в JPEG.

### Папки data/

Читает `../data/competitor-N/notes.md` по очереди. Скупые заметки со ссылкой дозаполняются с сайта.

### Отзывы

Только отзывы, без разбора лендинга. По домену строятся страницы BestChange:

- `https://www.bestchange.ru/<слаг>-exchanger.html?filter=reviews`
- `…?filter=claim` (финансовые претензии — спор о реальных деньгах)

Слаг = первая часть домена: `grumbot.net` → `grumbot`.

### Сравнение

Таблица из памяти, обновляется при каждом открытии вкладки.

- **Обновить курсы** — один заход в Chrome, читает семь таблиц BestChange, проставляет курс и способы выплаты всем известным обменникам (~20 сек).
- **Скачать CSV** — разделитель `;`, UTF-8 с BOM, Excel открывает без кракозябр.

Колонка «доверие» — не рейтинг биржи. Это оценка по чеклисту безопасности. Тяжёлый красный флаг ставит **потолок** (жалобы на блокировку карты — не выше 3 из 10), зелёный «быстрая поддержка» этот потолок не отменяет.

Курс в таблице только для чтения. Ручная правка из сравнения убрана: она тихо перебивала свежие данные BestChange.

### История

Лента разборов. Удаление обменника на карточке / в сравнении / в истории стирает его и из профиля, и из ленты.

## Откуда берётся курс ₽/USDT

Приоритет жёсткий:

1. Число, которое вписали руками во вкладке «Текст».
2. Таблица BestChange при сумме **1000 USDT**.
3. Число из заметки — только если оно в коридоре разумного курса (~30–200 ₽). Иначе это почти наверняка курс BTC или сумма сделки.

**С лендинга курс не берём.** Модель регулярно подставляет не то.

Порядок таблиц для курса (берётся первая, где обменник нашёлся):

1. Расчётный счёт RUB  
2. Банковский перевод RUB  
3. СБП  
4. Наличные RUB (`cash-ruble`, не `cash-rub` — второй адрес редиректит на главную)

Отдельно, только как каталог выплат, читаются Сбербанк, Т-Банк и карта Visa/MC. Их курс в колонку сравнения не идёт: это другой сегмент рынка.

Курс ЦБ (`/rate`) — справка для спреда, не курс обменника.

## Как считается доверие

1. Модель ставит `trust_score` 0–10 по чеклисту (текст, сайт, отзывы).
2. Код опускает оценку до потолка, если есть тяжёлая категория флага:

| Категория | Потолок | Пример |
|---|---|---|
| `card_block` | 3 | жалобы на блокировку карты/счёта после выплаты |
| `splitting` | 4 | дробление на мелкие случайные платежи |
| `after_payment` | 4 | документы / доплата / «ещё транзакция» после отправки крипты |
| `aml_hold` | 4 | заморозка под AML + комиссия за разморозку |
| `bank_access` | 4 | «телефон в руках», кабинет банка открыт на время сделки |

Лёгкие флаги (`sbp_only`, задержки, «слишком хороший курс») только минусуют балл, потолок не ставят.

3. Если модель балл не ставила, а флаги уже есть (типично для одного скрина) — запасная шкала «по флагам», в таблице это подписано.
4. В профиле несколько материалов усредняются **без веса**. Чистый лендинг 8 и жалоба в отзывах 3 дадут около 5.5. Это осознанный компромисс: смотри список флагов рядом с цифрой, не только саму цифру.

Дизайн (`design_score`) — «похоже ли на сервис с первого взгляда», не безопасность выплаты. Мошенник тоже может сделать красиво.

## Эндпоинты

Интерактивная схема: `http://127.0.0.1:8000/docs`.

| Метод | Путь | Зачем |
|---|---|---|
| GET | `/` | интерфейс |
| GET | `/health` | жив ли сервер |
| GET | `/config` | лимит очереди и список форматов для UI |
| POST | `/analyze/text` | текст / заметка |
| POST | `/analyze/file` | любой поддерживаемый файл |
| POST | `/urls/parse` | сырой текст → чистый список ссылок |
| POST | `/analyze/url` | один сайт: лендинг + отзывы + BestChange |
| POST | `/analyze/reviews` | только отзывы |
| POST | `/analyze/batch` | все `notes.md` из `data/` |
| GET | `/rate` | курс USD ЦБ |
| GET | `/summary` | сводная таблица |
| GET | `/summary/export` | та же таблица CSV |
| POST | `/summary/rates/refresh` | обновить курсы всем профилям |
| GET | `/competitors` | список профилей |
| POST | `/competitors/merge` | склеить два профиля (дубль имени) |
| POST | `/competitors/rename` | переименовать |
| POST | `/competitors/remove` | удалить одного обменника отовсюду |
| DELETE | `/competitors` | очистить всю память |
| GET / DELETE | `/history` | лента / очистить ленту |

Старого `POST /analyze/image` нет: картинки идут через `/analyze/file`. Старого `POST /summary/rate` (ручной курс в таблице) тоже нет.

## Критерии в промптах

Полный список с формулировками — в `backend/services/openai_service.py`, блок `SAFETY_CRITERIA_BLOCK`. Кратко:

**Зелёные:** выплата одним платежом; реквизиты счёта / банковский перевод (не только СБП); наличные (карта в сделке не участвует); AML **до** отправки крипты; фиксация курса в заявке; большой резерв и живые отзывы.

**Красные:** дробление выплаты; только СБП; блокировка карты после выплаты; AML/KYC **после** получения крипты + комиссия за разморозку; смена кошелька; увод в Telegram; «телефон в руках»; сид-фраза.

Маркетинг («24/7», «удобный интерфейс») в флаги не кладётся. Голословное «мошенники!» без даты и суммы — в `ignored_claims`, не в красные флаги.

Грабли разработки (reload после Selenium, битый URL наличных, курс с лендинга) — в отчёте урока, сюда не дублируем.
