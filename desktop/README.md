# Окно на PyQt6

Те же вкладки, что у сайта: анализ (ссылки, файлы, текст), папки `data/`, отзывы, сравнение, история.

Окно само поднимает API на `127.0.0.1:8000`. Если на этом порту уже работает **наш**
сервер — подключается к нему, второй раз не запускает. Если порт занят чем-то чужим
(старая сборка, зависший процесс) — молча берёт ближайший свободный: 8001, 8002 и так далее.
Фактический адрес виден в строке состояния окна.

Проверка «наш или не наш» идёт по `/config`, а не по `/health`: последний отвечает
и у старых версий, из-за чего окно однажды тихо подключилось к зависшему серверу
и показывало 404 на новых вкладках.

Свой порт можно задать переменной окружения:

```powershell
$env:CM_PORT = "8010"; .\competitionmonitor.exe
```

## Запуск из исходников

Из папки `competitor-monitor`, виртуальное окружение уже с библиотеками сайта:

```powershell
.\.venv\Scripts\python.exe -m pip install -r desktop\requirements.txt
.\.venv\Scripts\python.exe desktop\main.py
```

Нужен файл `.env` с ключом ProxyAPI — как для сайта (в папке проекта или на уровень выше). Содержимое файла в чат не копируем.

Нужен Google Chrome: разбор сайтов идёт через него, даже если окно не браузер.

## Сборка .exe

```powershell
.\.venv\Scripts\python.exe desktop\build.py
```

После сборки запуск:

`desktop\dist\competitionmonitor\competitionmonitor.exe`

Это имя из ДЗ: `competitionmonitor.exe`. Рядом лежат библиотеки — папку `competitionmonitor` копируй целиком, один файл без соседей не откроется.

Один огромный файл (дольше стартует):

```powershell
.\.venv\Scripts\python.exe desktop\build.py onefile
```

Тогда exe будет в `desktop\dist\competitionmonitor.exe`.

Положи `.env` **в ту же папку, что и exe**. Chrome должен быть установлен.

Вкладка «Папки data/» ищет `data/` рядом с exe или в текущей папке запуска.

Очистить черновики сборки:

```powershell
.\.venv\Scripts\python.exe desktop\build.py clean
```

Если окно не открылось — смотри `desktop-error.log` рядом с exe.

`.exe` в git не кладём: тяжёлый бинарник, ключ туда не попадает, но и пользы в репозитории нет.
