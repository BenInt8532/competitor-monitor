# competitor-monitor — проект ДЗ урока PEm08

AI-анализатор конкурентов для ниши **крипто-обменников** (USDT → RUB, выплата по
реквизитам счёта / банковским переводом). Черновик собран ассистентом по образцу
демо-проекта урока (`../cursor_.md`), финальная доводка и запуск — в Cursor, руками Ben.

## Логика (кратко)

- Анализ текста / изображения / сайта по URL / batch-анализ всех `../data/*` разом
- Каждый анализ ищет **red_flags** и **green_flags** по критериям безопасности,
  которые сформулировал Ben (полный список — в `../otchet-PEm08-multimodalnoe-prilozhenie.md`)
- Курс обменника сравнивается с официальным курсом ЦБ РФ (бесплатный XML API, без ключа)
- Сводная таблица `/summary` сравнивает всех проанализированных конкурентов

## Структура

- `backend/` — FastAPI: `main.py` (эндпоинты), `config.py`, `models/schemas.py`, `services/*`
- `frontend/` — статический HTML/CSS/JS, 6 вкладок
- `.env` **не здесь** — лежит в корне папки урока (`../.env`), `config.py` читает его оттуда
- `run.py` — запуск: `python run.py` или `uvicorn backend.main:app --reload`
